# ito オンライン

ブラウザで遊べる、オンライン・マルチプレイ対応の協力型パーティーゲーム「ito」です。
Node.js + Express + Socket.IO で動作します。

## 遊び方

1. 名前を入れて「部屋を作る」→ 招待リンク(または4文字の部屋コード)を友達に送る
2. ホストが「ゲーム開始」すると、全員に 1〜100 のカードが配られ、お題が出ます
3. 自分のカードには数字が見えます。お題に沿って、数字の大きさを表す言葉をカードに書き込みます
   （例: お題「動物の強さ」で 95 → 「ライオン」、5 → 「アリ」）
4. 他の人のカードは裏向きで、書き込まれた言葉だけが見えます
5. みんなでカードをドラッグして、左から小さい順に並べ替えます（誰のカードでも動かせます）
6. 全員が「この順番でOK！」を押したら答え合わせ。左から1枚ずつめくり、全部小さい順なら成功！

- 2〜10人、1人あたりのカード枚数はロビーで設定可能
- リロードや回線切れでも同じブラウザなら自動で復帰します
- チャット付き

## ローカルで動かす

```bash
npm install
npm start
# http://localhost:3000
```

## Render にデプロイ

1. このリポジトリを GitHub に push
2. [Render](https://render.com) → **New +** → **Blueprint** → リポジトリを選択
   （`render.yaml` が読み込まれ、無料プランの Web Service が作成されます）
3. 発行された `https://itogame-xxxx.onrender.com` を友達に共有

※ Render 無料プランは15分アクセスがないとスリープし、次回アクセス時の起動に数十秒かかります。
※ 部屋はサーバーのメモリ上に保持されるため、再起動すると部屋は消えます。
